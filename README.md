# AyuGram 漂浮音频

AyuGram Floating Audio

一款为 AyuGram 开发的悬浮音频控制插件，旨在改善音频播放时的操作体验，并提供可自定义的悬浮控制界面。

## 📦 当前版本

**v0.11.0-beta.1**

当前为测试版本，可能仍存在尚未发现的 Bug、兼容性问题或性能问题。

## 🔧 项目文件

- `floating_audio_v0.11.0-beta.1.plugin` — 插件文件
- `变更与安装说明.md` — 版本变更记录和安装说明
- `读取日志覆盖报告.py` — 日志分析辅助工具

## 🐛 问题反馈

欢迎通过 GitHub Issues 提交以下反馈：

- 功能异常、闪退和兼容性问题
- 性能问题和资源占用异常
- 代码质量、安全性和潜在缺陷
- 现有功能的交互体验和设计不足
- 代码优化及维护性改进建议

提交 Bug 时，请尽可能提供问题描述、复现步骤、预期结果、实际结果和相关日志。

**注意：本项目目前主要收集 Bug 报告、代码审查意见及现有功能的改进建议，暂不征集新功能需求。**
